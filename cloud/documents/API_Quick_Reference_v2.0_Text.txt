IoT Cloud Platform 
API Quick Reference 
Base URL:  http://<server-ip>:3000/api/v1 
Auth column legend: 
  JWT  — Include header:  Authorization: Bearer <access_token> 
  Key  — Device endpoints: pass device_id + secret_key in body/query string 
  None — No authentication required 
 
All responses follow the envelope:  { "success": true/false, "data": {...}, "error": {...} } 
Timestamps use ISO-8601 format (e.g. 2026-05-23T17:00:00.000Z)

interval defaults to 1h if omitted. Only numeric types support aggregation (not string). 
Aggregate uses TimescaleDB time_bucket() — highly efficient for large datasets.

10. STANDARD ERROR CODES 
Error Code HTTP 
Status 
When It Occurs 
VALIDATION_ERROR 400 Request body/params failed schema validation 
MISSING_PARAMS 400 Required query params (from, to) are missing 
INVALID_INTERVAL 400 Aggregate interval is not one of the allowed values 
MISSING_REQUIRED_PARAM 400 A required command parameter was not supplied 
INVALID_PARAM_TYPE 400 Command parameter value does not match declared type 
UNSUPPORTED_TYPE 400 Aggregation requested on a string variable 
UNAUTHORIZED 401 Missing or expired JWT access token 
INVALID_CREDENTIALS 401 Wrong email or password on login 
INVALID_REFRESH_TOKEN 401 Refresh token is invalid, expired, or already used 
DEVICE_UNAUTHORIZED 401 Device secret_key does not match stored hash 
NOT_DEVICE_OWNER 403 Template belongs to a device not owned by caller 
PROJECT_NOT_FOUND 404 Project does not exist or belongs to another user 
DEVICE_NOT_FOUND 404 Device does not exist or belongs to another user 
SENSOR_NOT_FOUND 404 Sensor does not exist or belongs to another user 
VARIABLE_NOT_FOUND 404 Variable does not exist or belongs to another user 
TEMPLATE_NOT_FOUND 404 Command template not found 
INSTANCE_NOT_FOUND 404 Command instance not found or already acknowledged 
EMAIL_ALREADY_EXISTS 409 Email is already registered 
DEVICE_NAME_EXISTS 409 Device name already used within this project 
LABEL_ALREADY_EXISTS 409 Variable label already used on this sensor 
TEMPLATE_NAME_EXISTS 409 Command template name already used on this device 
INTERNAL_ERROR 500 Unexpected server error
