IoT Cloud — API Reference

All endpoints use JSON. Authenticated routes require a Bearer token in the Authorization header. All timestamps are ISO 8601 UTC. All IDs are UUIDs.

Connect to ?token=<access_token>. After connecting, subscribe to a device's feed. All messages are JSON with a type field.

Deployment note: the reference gateway currently does not expose a /ws route, so real-time push is unavailable and the console loads data on demand. These frames describe the intended contract.
↑ Client → Server: subscribe
Subscribe to real-time events for one or more devices

Device Ingest
Device-facing routes. These are not JWT-authenticated: each call must carry the device's device_id and its secret_key (returned once when the device was created). A missing credential pair returns 400; a mismatched one returns 401 DEVICE_UNAUTHORIZED.
POST
/ingest/telemetry
Publish one or more sensor readings. Up to 500 readings per call; each variable_id must belong to the calling device.
Device key
▼
Request body
Response
FieldTypeRequiredDescription
device_idstringrequiredUUID of the sending device
secret_keystringrequiredDevice secret issued at creation
readingsarrayrequired1–500 reading objects
readings[].variable_idstringrequiredUUID of the target variable on this device
readings[].valuenumber | string | booleanrequiredMust match the variable's data_type
readings[].recorded_atstringoptionalISO 8601 UTC. Defaults to server receive time

Webhooks
Outbound event delivery to your own HTTPS endpoint. Requires a plan with webhooks_enabled. The signing secret is returned once, in the creation response.
Verified contract. The request body accepts only the three fields below. Any additional field, and any event value outside the enum, is rejected with 400.
POST
/webhooks
Register an outbound webhook and receive its signing secret.
Auth required
▼
Request body
Response
FieldTypeRequiredDescription
urlstringrequiredHTTPS endpoint that will receive deliveries
event_typesarrayrequiredOne or more values from the event enum below. This is the only accepted key name
enabledbooleanrequiredWhether deliveries are active

Example
{
  "url": "https://api.yourdomain.com/webhooks",
  "event_types": ["device.online", "command.success"],
  "enabled": true
}

Allowed event_types (strict enum)
ValueFires when
device.onlineA device reports in after being offline
device.offlineA device stops reporting
command.successA dispatched command is acknowledged as executed
command.failedA dispatched command is acknowledged as failed

  "success": true,
  "data": {
    "id": "7c9bc7b1-aa08-40a1-8178-30a6a08b3394",
    "url": "https://api.yourdomain.com/webhooks",
    "event_types": ["device.online", "command.success"],
    "enabled": true,
    "created_at": "2026-09-26T16:20:18.472Z",
    "secret": "fbde143c23b8e001d2a9ef0f1fb90ed4a2ab60d514700fe0"
  }
}
